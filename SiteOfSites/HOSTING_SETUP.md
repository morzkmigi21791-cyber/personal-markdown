# Настройка хостинга сайтов с поддоменами

## Обзор

Система Site of Sites теперь поддерживает хостинг статических сайтов с поддоменами. Пользователи могут:

- Создавать проекты с поддоменами
- Загружать файлы сайтов (HTML, CSS, JS, изображения)
- Настраивать видимость сайта (приватный, публичный, по ссылке)
- Активировать/деактивировать сайты
- Получать доступ к сайтам по адресу `http://SUBDOMAIN.localhost`

## Архитектура

### Backend (FastAPI)
- **Модель Project** расширена полями для хостинга:
  - `subdomain` - поддомен сайта (уникальный)
  - `visibility` - видимость (private/public/link_only)
  - `is_active` - активен ли сайт
  - `index_file` - главный файл сайта (по умолчанию index.html)
  - `custom_domain` - кастомный домен (для будущего)

- **API Endpoints**:
  - `GET /api/projects/{id}/hosting` - информация о хостинге
  - `PUT /api/projects/{id}/hosting` - обновление настроек хостинга
  - `GET /api/sites/{subdomain}` - публичный доступ к сайту
  - `GET /api/sites/{subdomain}/{filename}` - отдача файлов сайта
  - `GET /api/hosting/check-subdomain/{subdomain}` - проверка доступности поддомена

### Frontend (React)
- **SiteHostingModal** - модальное окно для управления хостингом
- **ProjectFileModal** - обновлен с кнопкой "Хостинг"
- **UserProfilePage** - отображает статус хостинга проектов

### Nginx (Docker)
- Проксирует запросы к поддоменам на FastAPI
- Обрабатывает статические файлы через API
- Показывает 404 для несуществующих сайтов

### MinIO (Docker)
- Хранит файлы сайтов в структуре: `{user_id}/{project_id}/{filename}`
- Поддерживает все типы статических файлов

## Установка и запуск

### 1. Запуск всех сервисов
```bash
# Windows
start.bat

# Или по отдельности
docker-compose up -d  # Nginx + MinIO
cd backend && python run.py  # Backend
cd frontend && npm start  # Frontend
```

### 2. Настройка hosts файла (Windows)
Добавьте в файл `C:\Windows\System32\drivers\etc\hosts`:
```
127.0.0.1 localhost
127.0.0.1 *.localhost
```

### 3. Настройка hosts файла (Linux/Mac)
Добавьте в файл `/etc/hosts`:
```
127.0.0.1 localhost
127.0.0.1 *.localhost
```

## Использование

### 1. Создание проекта с хостингом
1. Войдите в систему
2. Перейдите в свой профиль
3. Создайте новый проект
4. Нажмите на проект для управления файлами
5. Нажмите кнопку "🌐 Хостинг"
6. Настройте поддомен и параметры

### 2. Загрузка файлов сайта
1. В модальном окне файлов выберите "Корневая папка"
2. Загрузите файлы сайта (index.html, style.css, script.js и т.д.)
3. Убедитесь, что главный файл называется как указано в настройках

### 3. Активация сайта
1. В настройках хостинга укажите поддомен
2. Выберите видимость сайта
3. Включите переключатель "Активировать сайт"
4. Сохраните настройки

### 4. Доступ к сайту
После активации сайт будет доступен по адресу:
- `http://YOUR_SUBDOMAIN.localhost` (порт 80)
- `http://YOUR_SUBDOMAIN.localhost:3000` (порт 3000)

## Настройки видимости

- **Приватный** - доступен только владельцу
- **Публичный** - доступен всем пользователям
- **По ссылке** - доступен только по прямой ссылке

## Поддерживаемые файлы

- HTML файлы (.html, .htm)
- CSS файлы (.css)
- JavaScript файлы (.js)
- Изображения (.png, .jpg, .jpeg, .webp, .svg)
- Другие статические файлы (.json, .txt, .ico)

## Ограничения

- Максимальный размер файла: 10MB
- Поддомен: 3-50 символов, только буквы, цифры и дефисы
- Поддомены должны быть уникальными
- Нельзя использовать поддомены, начинающиеся или заканчивающиеся дефисом

## Устранение неполадок

### Сайт не открывается
1. Проверьте, что сайт активирован
2. Убедитесь, что поддомен указан правильно
3. Проверьте настройки hosts файла
4. Убедитесь, что nginx запущен

### Ошибка "Поддомен уже занят"
1. Выберите другой поддомен
2. Проверьте, не используется ли поддомен в другом проекте

### Файлы не загружаются
1. Проверьте формат файла (должен быть в списке разрешенных)
2. Убедитесь, что размер файла не превышает 10MB
3. Проверьте подключение к MinIO

## Остановка сервисов

```bash
# Windows
stop.bat

# Или вручную
docker-compose down
# Закройте окна Backend и Frontend
```

## Разработка

### Добавление новых типов файлов
Обновите `ALLOWED_FILE_EXTENSIONS` и `ALLOWED_MIME_TYPES` в `backend/config.py`

### Изменение настроек nginx
Отредактируйте `nginx/nginx.conf` и перезапустите Docker:
```bash
docker-compose down
docker-compose up -d
```

### Изменение настроек MinIO
Обновите переменные окружения в `docker-compose.yml`
