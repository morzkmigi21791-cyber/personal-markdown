## Что сделал:
Получил задание компании на создание сайта для генерации 100 контактов и 100 компаний а также случайная привязка контактов к компаниям в системе Битрикс24 через вебхук. Первые 2 дня ушли на изучение что такое вебхуки, для сего они нужны и как использовать для задания, что такое битрикс24, а также API битрикс24. В своём кабинете битрикс24 я открыл входящий вебхук. API битрикс24 имеет множество функций, и открытие вебхука позволяет выбрать определённые методы, не давая использовать весь функционал, для нашей задачи нужен только CRM. 03.10 был готов функционал, запрос на генерицию выполняется полностью до 8 минут, для случайной генерации используются библиотеки Faker и requests. Проект состоит из python файла, являющийся бэкенд, и html документа с кнопкой и скриптом для запросов в битрикс для загрузки компаний и их контактов.

## Новые термины:
Вебхук — механизм передачи данных между приложениями в реальном времени, который автоматически отправляет уведомление и данные другому сервису при возникновении определенного события

Битрикс24 - онлайн-платформа с набором инструментов для совместной работы, управления бизнесом и автоматизации процессов. Она включает в себя CRM-систему, задачи и проекты, чаты, телефонию, создание сайтов и магазинов, а также аналитику и отчетность
