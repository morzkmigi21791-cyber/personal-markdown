# Задача
Сервис сейчас выполняет свои основные функции по хостингу, но всегда есть куда стремиться. На данные момент требуется добавить разные функции при хостинге сайтов, улучшить интерактив и визуал сервиса, добавить возможность изменения своего профиля.
Данный промежуток времени был сосредоточен только на добавление новых функций работы с профилем и проектами
## Что сделал
Одними из важных функций были добавлены новые настройки для проектов, возможность просмотреть свои файлы на прямо на сервисе,изменение в профиле фона, шапки и т.д. на свои изображения

Изменения:
- Добавлена возможность писать свой домен для проекта
- Добавлена возможность выбирать главный файл проекта
- В профиле можно изменить основной фон, шапку, фон проектов на своё изображение
- Можно поменять цвет проектов
- Можно изменить отображение файлов проекта
- Можно просмотреть файлы проекта

## Итоги
Данные изменения стали отличной основой, но они всё ещё требуют полировки и расширения
