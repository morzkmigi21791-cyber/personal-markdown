## Что сделал
Первым делом, убрал из фронтенд скрипт и перевёл проект на fastapi + react, теперь фронтенд не имеет возможность узнать вебхук битрикс или обратиться не по назначению. Для уменьшения времени на запросы добавления контактов или компаний, а также распределения контактов по компаниям, используется batch API, в Bitrix24 есть метод для работы с batch - crm.item.batchImport. Чтобы пользователь не мог отправлять много запросов за раз, было принято решение централизировать страницы при помощи Broadcastchannel, который делает так, что все открытые страницы как одна, на всех транслируется одно и тоже. Это поможет с тем, если пользователь захочет отправить много запросов с 1 компьютера.  Для открытия проекта в сеть используется российский сервис cloudpub. Сейчас проект можно назвать готовым к использованию, генерация выполняется менее чем за минуту, сайт открывается в интернет. 
## Новые термины:
Batch API - интерфейс программирования приложений, позволяющий объединять несколько запросов в один, что снижает нагрузки на сеть и ускоряет выполнение операций

BroadcastChannel - это механизм, позволяющий обмениваться сообщениями между различными окнами, вкладками и фреймами одного браузера, при условии, что они принадлежат одному источнику

CloudPub - российский сервис, создающий безопасный публичный доступ к локальным ресурсам через интернет с помощью туннеля
